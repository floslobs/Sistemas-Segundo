## 👩‍💻 Sobre esta experiencia

Este repositorio reúne los trabajos prácticos, ejercicios y proyectos que fui desarrollando durante el **segundo año de la carrera de Analista en Sistemas**.

En esta etapa avancé hacia el desarrollo de aplicaciones utilizando **C# y .NET**, incorporando la programación orientada a objetos, el diseño de interfaces gráficas y la conexión con bases de datos relacionales.

A diferencia del primer año, donde el foco estuvo en aprender lógica de programación y resolver problemas mediante código, este recorrido estuvo orientado a construir aplicaciones más completas, organizadas en distintas capas y capaces de gestionar información persistente.

Trabajé con Windows Forms, SQL Server, consultas SQL, acceso a datos, validaciones y separación de responsabilidades entre la interfaz, la lógica del negocio y la comunicación con la base de datos.

## 🚀 Mi recorrido de aprendizaje

### 01. Programación orientada a objetos

Comencé a trabajar con una forma más organizada de desarrollar aplicaciones, utilizando los principios de la programación orientada a objetos.

- Clases y objetos.
- Atributos y propiedades.
- Constructores.
- Métodos y encapsulamiento.
- Instanciación de objetos.
- Colecciones y listas (`List<T>`).
- Relaciones entre clases y objetos.

### 02. C# y Windows Forms

Incorporé el desarrollo de aplicaciones de escritorio con interfaces gráficas.

- Formularios y controles.
- Eventos y métodos asociados a botones.
- TextBox, ComboBox, DataGridView y otros controles.
- Validación de datos ingresados.
- Navegación entre formularios.
- Diseño de interfaces y componentes personalizados.
- Organización del código mediante archivos parciales.

### 03. Bases de datos y SQL Server

Profundicé en el almacenamiento y la administración de información mediante bases de datos relacionales.

- Creación y diseño de bases de datos.
- Tablas, campos y tipos de datos.
- Claves primarias y foráneas.
- Relaciones entre tablas.
- Consultas `SELECT`, `INSERT`, `UPDATE` y `DELETE`.
- Restricciones e integridad referencial.
- Consultas con múltiples tablas.
- Manejo de registros y operaciones sobre datos.

### 04. Conexión entre C# y bases de datos

Aprendí a conectar las aplicaciones con SQL Server para consultar y modificar información.

- Conexiones mediante `SqlConnection`.
- Ejecución de consultas con `SqlCommand`.
- Lectura de resultados.
- Parámetros SQL.
- Operaciones de alta, baja y modificación.
- Acceso a datos mediante clases DAL.
- Manejo de conexiones y excepciones.

### 05. Arquitectura por capas

Uno de los avances importantes fue aprender a separar las responsabilidades de una aplicación.

- **FE (Front End):** interfaz gráfica e interacción con el usuario.
- **BE (Business Entity / Business Logic):** representación de entidades y lógica del negocio.
- **DAL (Data Access Layer):** comunicación con la base de datos.
- Separación de responsabilidades.
- Organización del código en carpetas y clases.
- Reutilización de métodos y validaciones.

### 06. Validaciones y manejo de información

Incorporé controles para mejorar la consistencia de los datos y el funcionamiento de las aplicaciones.

- Validación de campos obligatorios.
- Control de tipos y formatos de datos.
- Manejo de excepciones.
- Validaciones mediante clases específicas.
- Tratamiento de información antes de guardarla.
- Control de registros activos e inactivos.

### 07. Desarrollo de aplicaciones integradoras

Apliqué los conocimientos adquiridos en proyectos que simulan situaciones de uso reales, como la administración de empleados, el control de horas trabajadas, la liquidación de pagos y la gestión comercial de una tienda.

## ▶️ Cómo ejecutar los proyectos

Los proyectos de escritorio fueron desarrollados utilizando Visual Studio y Windows Forms.

1. Abrir la solución `.sln` correspondiente con Visual Studio.
2. Configurar la cadena de conexión a SQL Server cuando el proyecto lo requiera.
3. Verificar que la base de datos correspondiente esté creada y disponible.
4. Restaurar los paquetes NuGet necesarios.
5. Compilar y ejecutar el proyecto desde Visual Studio.

**Requisitos generales:**
- Windows.
- Visual Studio con soporte para desarrollo de escritorio con .NET.
- SDK de .NET compatible con el proyecto.
- SQL Server y SQL Server Management Studio para los proyectos que utilizan bases de datos.

## 💡 Reflexión final

El segundo año representó un paso importante en mi formación como Analista en Sistemas. Dejé de trabajar únicamente con pequeños programas y comencé a desarrollar aplicaciones con estructuras más complejas, interfaces gráficas y conexión con bases de datos.

Aprendí que programar no consiste solamente en escribir código que funcione, sino también en organizarlo, separar responsabilidades, validar información y construir soluciones que puedan mantenerse y ampliarse.

Proyectos como AppTienda y EManzanilla me permitieron llevar los conocimientos teóricos a desarrollos más cercanos a situaciones reales.

Cada práctica y cada proyecto fueron parte de un proceso de aprendizaje que me permitió avanzar hacia nuevas tecnologías y desafíos de desarrollo.
